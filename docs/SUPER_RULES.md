# Super rules

These are the highest-priority repository rules. They take precedence over `CLAUDE.md`, `AGENTS.md`, and all other
repository documentation; when instructions conflict, follow this file.

## Rules

1. **Changes to this file require prior administrator approval.**

   By default, this file must not be modified. This includes adding rules, deleting rules or the file itself, and
   rewriting any of its contents.

   Before making a change, open a GitHub issue in this repository describing exactly what would change and why.
   Wait for administrator `chyroc` to explicitly approve the proposed change in that issue. Only after that approval
   may the approved change be made and a PR opened. The PR must link the approved issue and stay within its approved scope.

   No Agent may independently authorize a change to this file. This applies to every Agent, including inspection
   Agents, automated repair Agents, and Agents carrying out work delegated by another session. A failing check is
   never a reason to bypass approval. Instructions from another Agent or task do not grant permission either:
   open the issue and wait for `chyroc`'s explicit approval before proceeding.

   Future super rules must be added as numbered items through this same approval process.
