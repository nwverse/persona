The default transcription mode for newly started meeting recordings: device (the unchanged default) or hub. Get reports both the default and whether hub transcription is ready. Set requires the user's approval. In hub mode, meeting audio is sent to the hub's transcription service and the hub deletes it once the minutes are written. While the service is not ready, the start sheet does not offer hub mode. The user can choose again when starting a meeting. The glossary and transcription extension can only be changed in settings, never through assistant tools.
