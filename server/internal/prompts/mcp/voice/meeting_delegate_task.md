把用户的问题交给这场会议的会议对话（这次通话绑定的就是它）：调用时立刻发出去，不复述、不等确认。调用不会马上返回：告诉用户一声在问了；会议对话答完，这次调用的结果就是它的回答（可能要一会儿），那时用自己的话简短说出来，不加自己的内容。task 就是用户问的事，写成一个完整的问题或要办的事（会议对话看不到这次语音的上下文），照用户的意思写，不加别的。

```json
{
  "type": "object",
  "required": ["task"],
  "properties": {
    "task": {"type": "string", "description": "要问会议对话的问题或要它办的事，完整的一句或几句话"}
  }
}
```
