The Inbox rows of the user's newest iMessage / SMS conversations (those of the last week), as Persona's Inbox gets them: one a conversation, with who it is, whether it is a group, the last messages of an unread one, whether it is read or the user wrote last, and the link that opens it in Messages. For a subscription that brings iMessage into the Inbox; to read conversations use imessage_chats and imessage_read.
