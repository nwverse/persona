# Managing work in Persona

Choose the action from what the person wants to happen now. Use the Persona tools available in this conversation.

- **Record.** “Add preparing the checklist to my to-dos” asks for one saved item. Record it and stop. See [To-dos and reminders](references/record.md).
- **Delegate.** “Have someone prepare that checklist and bring it back for review” asks for execution. Find the existing item, request a linked plan, and report its actual state or the reason Persona refused the link. See [Delegating work](references/delegate.md).
- **Supervise.** For “How is the checklist coming along?” read the current task and its evidence. Contact the Agent only for new work or a change of direction. See [Progress and follow-up](references/progress.md).
- **Review.** When a result comes back, compare it with the agreed criteria. The current conversation’s role and the owner’s request determine who can accept it. See [Reviewing results](references/review.md).

Tool contracts define inputs and permissions. A plan awaiting Start, a queued dispatch, a running Agent and a result awaiting review are different states. Use the latest recorded state in your reply.
